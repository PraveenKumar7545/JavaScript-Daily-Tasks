# JavaScript Daily Tasks

A collection of **daily JavaScript practice tasks and mini projects** created while learning JavaScript from beginner to intermediate level.

🔗 **Live Demo:**
https://praveenkumar7545.github.io/JavaScript-Daily-Tasks/

---

## 📌 Project Overview

This repository contains **19 days of JavaScript practice** with **46 individual tasks** and **3 mini projects**.

The tasks cover important JavaScript concepts such as:

* Conditions
* Loops
* Arrays
* String Methods
* Functions
* Objects
* DOM Manipulation
* DOM Events
* Form Validation
* Array Methods
* LocalStorage
* CRUD Operations
* Fetch API
* Async/Await
* API Data Handling

The main purpose of this repository is to practice JavaScript concepts through small, beginner-friendly tasks and gradually build practical projects.

```bash

```

Open the required `index.html` file in your browser.
