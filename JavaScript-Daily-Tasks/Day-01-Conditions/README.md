# Day 01 - JavaScript Conditions 🚀

Day 01 focuses on practicing basic JavaScript conditional statements and decision-making through simple beginner-friendly tasks.
  
---

## 📝 Tasks

### 1. Positive / Negative

Checks whether the given number is positive or negative using JavaScript conditions.

### 2. Odd / Even

Checks whether the given number is odd or even using the modulus operator and conditional statements.

### 3. Voting Eligibility

Checks whether a person is eligible to vote based on their age.

### 4. Marks / Grade

Determines the grade based on the marks entered by the user.

---

## 🛠️ Technologies Used

- HTML5
- JavaScript
- Conditional Statements
- `if`
- `else if`
- `else`
