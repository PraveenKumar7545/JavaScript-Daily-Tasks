# Mini Project 01 - Student Management System

A beginner-friendly **Student Management System** built using **HTML, CSS, and JavaScript**.

This project allows users to add student details, display student records, and manage student information using JavaScript DOM manipulation.

## 🚀 Features

- Add student details
- Display student records
- Delete student records
- Simple and clean user interface
- Responsive design
- JavaScript DOM manipulation
- Form validation
- No backend or database required
