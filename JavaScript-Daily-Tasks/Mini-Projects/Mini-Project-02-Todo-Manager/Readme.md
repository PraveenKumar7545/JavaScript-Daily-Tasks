# Mini Project 02 - Todo Manager

A beginner-friendly **Todo Manager** web application built using **HTML, CSS, and JavaScript**.

This project allows users to add tasks, view their todo list, mark tasks as completed, and delete tasks.

## 🚀 Features

* Add new tasks
* Display todo items
* Mark tasks as completed
* Delete tasks
* Simple and clean user interface
* Responsive design
* JavaScript DOM manipulation
* Beginner-friendly implementation
* No backend or database required

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation

## ⚙️ How It Works

1. Enter a task in the input field.
2. Click the **Add Task** button.
3. The task is added to the todo list.
4. Mark a task as completed when it is finished.
5. Delete a task when it is no longer needed.
