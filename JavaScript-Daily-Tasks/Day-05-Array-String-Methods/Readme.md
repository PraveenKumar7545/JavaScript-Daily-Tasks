## 🔹 Task 13 — Array Map Methods

This task focuses on using the JavaScript `map()` method to process and transform values inside an array.

### Example

```javascript
const nums = [1, 2, 3];

const result = nums.map(num => num * 2);

console.log(result);
```

### Output

```text
[2, 4, 6]
```

The `map()` method creates a **new array** by applying a given operation to every element of the original array.
