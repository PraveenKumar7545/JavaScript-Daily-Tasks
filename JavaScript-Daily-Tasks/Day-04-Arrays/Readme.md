# Day 04 – JavaScript Arrays

This day focuses on practicing **JavaScript Arrays** using basic array operations, loops, conditions, and data processing.

## 📚 Tasks Completed

| Task | Topic | Description |
|------|-------|-------------|
| Task 09 | Array Sum | Calculates the sum of all elements in an array |
| Task 10 | Largest Number | Finds the largest number from an array |
| Task 11 | Count Occurrences | Counts how many times a value appears in an array |
| Task 12 | Reverse Array | Reverses the elements of an array |
